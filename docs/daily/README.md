# Daily record

One file holds each calendar day's completed history, consequential decisions,
learning evidence, and session plans. Keep the current handoff in
[status.md](../status.md), the decision index in [decisions.md](../decisions.md),
the history index in [history.md](../history.md), and competency states in the
[learning ledger](../learning/README.md).

- [2026-09-28](2026-09-28.md) — migration, fresh-code choice, initial stack
- [2026-09-29](2026-09-29.md) — foundation plan, M0 implementation, OpenRig setup, learning checks

Add later work to `YYYY-MM-DD.md` for the day it happened. Use sections for
history, decisions, learning evidence, and plans only when that day has content
for them. Keep actual answers and measured results attributed to their day.
Former FleetLoop session plans under `docs/archive/` remain historical references.
